# Extract the Group Name from a Section 2 Key

Removes the prefix and the following space from a Section 2 group key
and returns the remaining group name.

## Usage

``` r
.resy_group_name(key)
```

## Arguments

- key:

  character scalar representing a group key such as \`"### Forest"\` or
  \`"##D Wet meadow"\`.

## Value

character scalar with the group name only.
