# European countries at high resolution (EPSG:25832)

Country boundaries (NUTS level 0, columns \`NUTS_ID\` and \`NUTS_NAME\`)
at the 1:1 million scale, in EPSG:25832. Used to set \`Country\` in
\[resy_harmonize_eunis()\].

## Usage

``` r
data(europe_resolution_1_epsg25832)
```

## Format

An \`sf\` object with 37 polygons.

## Source

Eurostat GISCO: NUTS boundaries.
