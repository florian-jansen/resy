# Ecoregions of Europe (EPSG:25832)

The terrestrial ecoregions of Europe from the RESOLVE Ecoregions 2017
map, in EPSG:25832. Used to set `Ecoreg` (column `ECO_ID`) in
[`resy_harmonize_eunis()`](https://florian-jansen.github.io/resy/reference/resy_harmonize_eunis.md).

## Usage

``` r
data(ecoregions2017_epsg25832)
```

## Format

A plain coordinate list with 159 polygon features. See
[dunes_bohn_500mbuffer_epsg25832](https://florian-jansen.github.io/resy/reference/dunes_bohn_500mbuffer_epsg25832.md)
for the ring and attribute fields.

## Source

Dinerstein, E. et al. (2017): An ecoregion-based approach to protecting
half the terrestrial realm. BioScience 67. Licence CC-BY 4.0.
